MongoDB Task: Create the product Collection
Objective
Create a MongoDB collection named product using all lowercase letters inside the Registration DB.

1. Select the Registration Database
Input
use("Registration")
Expected Output
switched to db Registration
2. Create the Collection
Input
db.createCollection("product")
Expected Output
{ ok: 1 }
3. Verify the Collection
Input
show collections
Example Output
product
The output may also contain other collections already present in the Registration database.

4. Insert a Sample Document
db.product.insertOne({
    productId: 1,
    name: "Sample Product",
    category: "Electronics",
    price: 15000,
    quantity: 1,
    isActive: true
})
Example Output
{
    acknowledged: true,
    insertedId: ObjectId("...")
}
The actual ObjectId is generated by MongoDB and will be different in each database.

5. Display the Inserted Document
db.product.find()
Example Output
{
    _id: ObjectId("..."),
    productId: 1,
    name: "Sample Product",
    category: "Electronics",
    price: 15000,
    quantity: 1,
    isActive: true
}
6. Count Documents
db.product.countDocuments()
Expected Output
If only the sample document exists:

1
If the 5,000-product insertion script was executed successfully:

5000
7. Collection Name Requirement
The required collection name is exactly:

db.product
Correct:

db.product
Incorrect examples:

db.products
db.Product
db.PRODUCT
8. Final Command Set
use("Registration")

db.createCollection("product")

show collections

db.product.countDocuments()
9. Final Summary
Item	Value
Database	Registration
Collection	product
Naming style	Lowercase
Creation command	db.createCollection("product")
Verification command	show collections
The outputs marked as examples depend on the current state of your MongoDB database. Run the commands in your own MongoDB environment to obtain the actual results.
